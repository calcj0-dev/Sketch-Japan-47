# sim：採点方法の試算（2026-11-17）

採点を「重なりだけ」から「重なり4：らしさ6」に変えたときの試算。数字（`src/data/config.json` の `scoring`）を調整するときに使う。

| ファイル | 中身 |
| --- | --- |
| `lib.mjs` | 採点の試作（重なり・らしさ）と、手描きをまねた絵の生成（上手／ふつう／雑：形を大まかにする・線を揺らす・縦横比と向きのずれ） |
| `run.mjs` | 47県×描き方（丸・楕円・上手・ふつう・雑・別の県）×5回の重なりとらしさを `rows.json` に出す（約10秒） |
| `eval.mjs` | 採点方法の候補を同じデータで比べる |
| `robust.mjs` | 意地悪な描き方（回す・縦横比・左右反対・大げさ）での点数 |

使い方：`node sim/run.mjs && node sim/eval.mjs && node sim/robust.mjs`

## らしさとは
本物の形から「だいたいの楕円」（同じ重心・同じ広がりの楕円）を引いた残り＝出っ張り（＋）とへこみ（−）の地図を、本物と描いた形の両方で作り、少しぼかしてから相関をとる（−1〜1）。丸や楕円を描いただけでは 0 付近、半島や湾が同じ場所にあれば 1 に近づく。
